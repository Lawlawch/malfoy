# 《鉑金色的馬份》｜蛇與獅之歌　v0.2.1

哈利波特同人視覺小說。網頁版，手機、電腦都能玩，直向／橫向自動切換。

## 試玩
用 GitHub Pages 發布（Settings → Pages → 來源選 `main`、根目錄），打開網址即可，不需要安裝任何東西。
網址加 `?debug=1` 是測試模式：圖鑑可全部解鎖、主控台顯示數值、劇本有錯會提示。

## 檔案
| 位置 | 內容 |
|---|---|
| `index.html` | 入口（載入畫面、字體、引擎） |
| `story/*.txt` | 各章劇本（寫法見 `story/README.md`） |
| `story/story.js` | 章節清單、角色與表情、圖鑑、隱藏數值 |
| `engine/` | 引擎程式：`parser.js` 劇本解析、`player.js` 播放與存檔、`stage.js` 背景立繪、`ui.js` 對話框與輸入、`screens.js` 各畫面、`audio.js` 音效 |
| `engine/style/` | 外觀：`theme.css` 對話框、名牌、選項、工具列（墨綠＋金框）；`screens.css` 各畫面與羊皮紙面板 |
| `assets/bg/<名稱>.jpg` | 背景（等比例裁切填滿，重要內容放中央） |
| `assets/chara/<角色>/<表情>.png` | 立繪（半身，1200×1600 透明 PNG，規格見 `docs/sprite_spec.md`；目前是佔位圖）。有服裝的角色（目前只有馬份）是 `assets/chara/<角色>/<服裝>/<表情>.png`，例如 `draconia/noble/`、`draconia/school/` |
| `assets/avatar/<角色>.png` | 紀錄頭像 |
| `assets/cg/<id>.jpg` | CG：劇情中顯示（`@showcg`）與圖鑑共用；沒有圖時顯示佔位 |
| `assets/bgm/`、`assets/sound/`、`assets/voice/` | 音樂、效果音、語音（`.mp3`，目前還沒有） |
| `assets/font/` | 思源宋體分片（瀏覽器只下載用到的字） |
| `assets/ui/` | 介面小圖（等待點擊的羽毛筆，由 `tools/make_quill.py` 產生） |

## 功能
- 對話：逐字顯示、名牌、旁白與對話同一個框（旁白沒有名牌）、長句自動縮字、說話者高亮、等待點擊羽毛筆
- 操作：點畫面／Enter／滾輪向下＝下一句；右鍵＝隱藏對話框；滾輪向上＝紀錄；Esc＝關閉視窗
- 工具列：對話框內側底部靠右的一排圖示（自動、略過、紀錄、隱藏、存檔、讀檔、設定、標題），跟著對話框顯示與隱藏
- 存檔：手動 3 頁 × 6 格（縮圖、覆蓋確認、刪除）；任何時候都能存（打字中也可以，讀回從這一句重新顯示）
- 自動存檔：每句一次（略過期間暫停、停下時補寫）；首頁「繼續」回到離開前的那一句。讀完一章後「繼續」從下一章開頭
- 章節流程：每章開始前顯示章名過渡畫面（點一下可跳過）；年級最後一章結束後顯示年級結算（這一輪的結局 CG 與標題；返回標題／儲思盆／下一年級開始）；下一章還沒做好時顯示「劇本修葺中」
- 劇本更新後舊存檔仍可讀：改字不受影響；增刪句子時用存檔那一句的內容找回原位置（那一句被改寫就回到前一句沒改過的句子），只有整個場景被刪除或改名才退回段落開頭（自動判斷，不需改版本號）
- 儲思盆：依年級選章，一律當主線，沿用最近一次抵達該章時的數值
- 已讀記錄逐句計算；「只略過已讀」可在設定關閉
- 圖鑑：一般 CG（#1 起）／結局 CG（#501 起），每頁 6 個，不用捲動
- 設定：文字速度、自動速度、字體大小、只略過已讀、三種音量
