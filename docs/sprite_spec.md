# 立繪規格（《鉑金色的馬份｜蛇與獅之歌》）

用途：生成或繪製正式立繪時照這份做。角色與表情清單見 `docs/characters.md`，引擎登記在 `story/story.js`。
立繪改為**長立繪（9:16）**。舊的 3:4 立繪（1200×1600，含現有佔位圖）引擎照樣能用，兩種可以混用，換上正式圖時直接用同樣的檔名覆蓋即可。

---

## 一、檔案

| 項目 | 規格 |
|---|---|
| 畫布 | **1008 × 1792**（寬 × 高，9:16，Grok Imagine 的輸出尺寸，不用放大）。同一角色的所有表情、服裝都用同一個尺寸 |
| 格式 | **WebP**，**透明背景**（有損壓縮、品質約 90 即可；PNG 原圖交給引擎聊天室轉檔也可以） |
| 檔名 | `assets/chara/<角色代號>/<表情>.webp`；有多套服裝的角色是 `assets/chara/<角色代號>/<服裝>/<表情>.webp`，例如 `assets/chara/draconia/school/shy.webp` |
| 代號與表情 | 一律小寫英文，與 `story/story.js` 的 `faces` 相同 |

## 二、取景（長立繪）

```
┌──────────────┐  ← 畫布上緣
│   （留白）   │  頭頂上方留約 126px（約 7%），不要讓頭頂貼邊
│     ●●●      │  ← 頭部：高約 420px（約 23%，±15），左右置中，下巴約 y=546
│      ▌       │
│   ▛▀▀▀▀▜    │  ← 肩膀約在 y=640 附近
│   ▌    ▐    │
│   ▌    ▐    │  ← 約 y=1344：腰（上方這一段 = 舊規格的 3:4 半身）
│   ▌    ▐    │
│   ▌    ▐    │  ← 下半身（大腿左右）：平常藏在對話框後面或超出畫面
└──────────────┘  ← 畫布下緣：平切
```

- **從頭頂畫到大腿左右**，底邊直接平切到畫布下緣。
- **角色左右置中**。手、魔杖、頭髮可以超出身體，但不要超出畫布。
- 畫面上通常只露出頭到胸口，**表情與上半身動作是重點**。下半身大多被對話框遮住，只有直向單人、三角排前排時會露出一點到畫面底緣，手、長袍下擺的細節要求可以放寬，但不要明顯走樣。
- 引擎以「上方 3:4 段」（頭頂到 y≈1344）排位，所以頭部位置與大小必須照上面的比例，下半身畫多畫少不影響排位。

## 三、比例一致（最重要）

引擎是用「整張畫布」來縮放的，所以：

- **所有角色的頭部大小與位置要大致相同**（頭頂約在高度 7%（y≈126），頭高約 23%（≈420px），下巴約 y≈546）。不要因為某個角色比較高大，就在畫布裡把他畫大。舊規格 1200×1600 的比例相同（頭頂 y≈150、頭高 ≈500、下巴 y≈650）。
- **身高差交給引擎處理**：在 `story/story.js` 給角色加 `scale`，例如 `scale: 1.15`。放大時會往上長，頭比別人高。（海格目前暫設 1，因為 1.15 在橫向時頭頂會被裁切；正式圖到了再調整。）
- **同一角色的不同表情**：位置、大小、姿勢、服裝都要一致，只改臉（和必要的手勢）。換表情時才不會跳動。
- **同一角色的不同服裝**：頭部位置與大小也要一致，只換衣服。換裝時才不會跳動。

## 四、生成建議（例如用 ChatGPT）

- 先做出每個角色的 **normal**，滿意後，以它為底圖修改其他表情（例如「保持構圖、服裝、大小完全不變，只把表情改成害羞，臉頰微紅」）。
- 每次都指定：從頭頂到大腿、正面或微側、透明背景、9:16（1008×1792）、頭頂留白約 7%、頭部約佔畫面高度 23%、角色置中。
- 生成後檢查：頭頂位置、頭的大小是否跟其他角色差不多；背景是否真的透明（不是白底）。
- 畫風、線條、上色方式全角色統一。

## 五、引擎裡的顯示方式（參考）

- 以上方 3:4 段（頭頂到腰）對齊排位，下半身往下延伸：橫向藏在對話框後面、超出畫面下緣；直向單人時剛好到畫面底緣。
- 1 人置中；2 人左右；3 人時橫向左中右，**直向三角排**（左右兩人在前、貼到畫面底緣，劇本裡排在中間的人站後排，頭部夾在兩人之間，三人一樣大）。說話的人以外會稍微變暗。
- 換表情是立刻切換，所以同角色各表情的輪廓要對齊。
- 存檔縮圖也會畫出立繪，用的是同一套位置與大小（一律用橫向版面）。
