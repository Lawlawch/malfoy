# 立繪規格（《鉑金色的馬份｜蛇與獅之歌》）

用途：生成或繪製正式立繪時照這份做。角色與表情清單見 `docs/characters.md`，引擎登記在 `story/story.js`。
目前 `assets/chara/` 裡的是佔位圖（半身剪影），已經照這份規格畫好，換上正式圖時直接用同樣的檔名覆蓋即可。

---

## 一、檔案

| 項目 | 規格 |
|---|---|
| 畫布 | **1200 × 1600**（寬 × 高，3:4），所有角色、所有表情都用同一個尺寸 |
| 格式 | PNG，**透明背景** |
| 檔名 | `assets/chara/<角色代號>/<表情>.png`；有多套服裝的角色是 `assets/chara/<角色代號>/<服裝>/<表情>.png`，例如 `assets/chara/draconia/school/shy.png` |
| 代號與表情 | 一律小寫英文，與 `story/story.js` 的 `faces` 相同 |

## 二、取景（半身）

```
┌──────────────┐  ← 畫布上緣
│   （留白）   │  頭頂上方留約 150px（約 9%），不要讓頭頂貼邊
│     ●●●      │  ← 頭部：高約 380px，左右置中
│      ▌       │
│   ▛▀▀▀▀▜    │  ← 肩膀約在 y=560 附近
│   ▌    ▐    │
│   ▌    ▐    │
└──────────────┘  ← 畫布下緣：腰部平切（這段會藏在對話框後面）
```

- **從頭頂畫到腰部**，底邊直接平切到畫布下緣，不要畫出裙襬或腿。
- **角色左右置中**。手、魔杖、頭髮可以超出身體，但不要超出畫布。
- 畫面上通常只露出頭到胸口，**表情與上半身動作是重點**。腰部附近會被對話框蓋住。

## 三、比例一致（最重要）

引擎是用「整張畫布」來縮放的，所以：

- **所有角色的頭部大小與位置要大致相同**（頭頂約 y=150，頭高約 380）。不要因為某個角色比較高大，就在畫布裡把他畫大。
- **身高差交給引擎處理**：在 `story/story.js` 給角色加 `scale`，例如海格是 `scale: 1.15`。放大時會往上長，頭比別人高。
- **同一角色的不同表情**：位置、大小、姿勢、服裝都要一致，只改臉（和必要的手勢）。換表情時才不會跳動。
- **同一角色的不同服裝**：頭部位置與大小也要一致，只換衣服。換裝時才不會跳動。

## 四、生成建議（例如用 ChatGPT）

- 先做出每個角色的 **normal**，滿意後，以它為底圖修改其他表情（例如「保持構圖、服裝、大小完全不變，只把表情改成害羞，臉頰微紅」）。
- 每次都指定：半身、正面或微側、透明背景、1200×1600、頭頂留白、腰部切齊下緣、角色置中。
- 生成後檢查：頭頂位置、頭的大小是否跟其他角色差不多；背景是否真的透明（不是白底）。
- 畫風、線條、上色方式全角色統一。

## 五、引擎裡的顯示方式（參考）

- 立繪底部對齊：底邊在橫向畫面最下緣、直向畫面對話框後面，只露出上半身。
- 1 人置中；2 人左右；3 人左中右（人越多縮得越小）。說話的人以外會稍微變暗。
- 換表情是立刻切換，所以同角色各表情的輪廓要對齊。
- 存檔縮圖也會畫出立繪，用的是同一套位置與大小。
