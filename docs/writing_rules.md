# 《鉑金色的馬份｜蛇與獅之歌》劇本寫作規則

用途：劇本聊天室寫劇本時照這份規則寫。劇本寫在 Claude Doc《X 年級劇本》（第一個分頁是總覽，之後每章一個分頁），Lawch 審稿定稿後，由 Claude Code（引擎）讀文件轉成 `story/<章節id>.txt`、測試。劇本聊天室不用輸出 txt。
- 文件的標註寫法見第八節；引擎指令的寫法以 `story/README.md` 為準，這份不重複。
- 角色外觀、性格、口吻與已確定的設定，見 `docs/characters.md`。

---

## 一、作品設定
- 視角：哈利第一人稱，全篇繁體中文。
- 女主角：跩珂妮雅‧馬份（全名中間用「‧」）。日常稱「馬份」，熟人叫她「妮雅」，父母叫她「小水仙」。傲嬌系動漫風，口是心非。
- 四個學年，每年約 10～12 章。一年級對應《神秘的魔法石》，共十二章，有四個年級結局（y1_A～y1_D）與三種終結結局。
- 克拉、高爾在本作是**女生**（沿用姓氏，不寫壯碩）。
- **文風**：生動有趣，適時加入搞笑段落（例如角色的小糗事、反差的吐槽、旁白的自嘲）。搞笑點到為止，不要打斷關鍵選擇前後的氣氛。

## 二、羈絆與旗標
- 隱藏數值只有一個：**羈絆 bond**（與馬份），起始 50，範圍 0～100（引擎自動夾住），**永遠不顯示給玩家**。
  - 愈高，愈把她拉向光明；愈低，愈孤立，或被她拉向黑暗。
- 建議每章 4～8 個影響羈絆的選項（建議，不是硬性規定；劇情需要時可以更少或更多）。
  - 一般選項 ±1，關鍵選擇 +2～+5（第一章最多 +5），扣分 −1～−5。全年級要撐 11 章：全選最好的玩家，到第十章左右才接近 100。
  - **取捨型扣分**：「站在朋友那邊」「做對的事」但冷落她的選項，也要扣一點羈絆（例：先扶奈威、先開門逃命、叫她閉嘴），讓玩家要權衡，而不是永遠有明顯的最佳答案。
  - **門檻逐章提高**：第四章 ≥60、第六章 ≥65、第七章 ≥75，之後的章節繼續往上。
  - 純粹決定劇情走向的分支選擇，可以只記旗標、不動羈絆，避免懲罰玩家選路線。
- 旗標記錄選擇結果，讓後面的劇情對得上，跨章、跨年級都有效。
  - 一年級命名用 `c章節_事件=數字`，例如 `c1_hagrid=2`（維持原名，不改）。
  - 二年級起一律加年級前綴 `y年級c章_事件=數字`，例如 `y2c3_xxx=1`，避免和一年級同名旗標互相覆蓋。
  - 承接前章或前一年級的旗標時，寫明是哪一章的哪個旗標。
- **每個年級開始時羈絆重設**（起始值寫在該年級的總覽分頁），前面年級的旗標照樣有效。
- 選擇之後**不在畫面提示對哪個角色有影響**。隱藏數值的暗示只在特殊時刻用，草稿標 `［提示：文字］`。

## 四、硬規則
1. **一行只能是說話，或只能是動作／心理／環境描寫，不可混在一起。** 動作寫成獨立的旁白行。
2. **一行＝一個對話框，最多 80 字。** 超過就拆成兩行。
3. **角色一出場就以名字當說話者**（大家都知道哈利波特的人物）。`？？？` 只用於**刻意隱藏身份**的角色，要讓黑影上台時標 `［？？？ 登場］`（引擎轉成 `@show unknown`）。旁白依哈利的視角：哈利還不知道對方名字時，旁白可以稱「那女孩」「那個男人」。
4. **旁白＝說話者寫「旁白」**，遊戲裡跟對話用同一個墨綠對話框，只是沒有名牌、字色稍淡。哈利說話，說話者寫「哈利」。
5. 不要在同一行寫兩個人說話。
6. 用全形標點與「」對白；不用引號當強調（確有需要才用，一章最多三處）。
7. **選項出現前的最後一句，會在選擇時留在畫面上**，要寫成能引出選擇的一句（提問、僵局、危機）。
8. **說話的選項用「」包住；動作的選項不加任何標點**（例：「我也是葛來分多。」、握住她的手）。
9. **表情只能用第五節表格列出的表情。** 要新增表情，先跟 Lawch 確認。
10. **選擇題目**會直接顯示在遊戲的選項上方：寫成一句完整的問句，用哈利的心聲（例：「她向我伸出了手，我該怎麼做？」），**20 字以內**，不要劇透選項的後果。「一般／關鍵／分支」等分類寫在題目前的括號裡，只供參考，不會顯示。
11. **你／妳**：對女性說話一律用「妳」（哈利對馬份、榮恩對馬份等），對男性用「你」。Lawch 的草稿若寫錯，潤色時自動轉換。
12. 唸咒一律用「唸」，不用「念」。
13. **不單獨一行「……」表示說不出話**：寫成旁白（例：「她張了張嘴，什麼也沒說。」），或把「……」放在下一句開頭。「……！」表示嚇一跳可以保留。
14. **同一場景中途換地點或時間**（回到寢室、隔天早上）一定要寫［背景切換：代號］。
15. **演出寫在正文對應的位置**：換裝、換背景、站位、停頓、登場退場都寫在正文，不要只寫在附註。Claude Code 只照正文轉檔。

## 七、CG
- CG 一律是**哈利的第一人稱視角**：
  - 哈利的臉、頭、身體**不入鏡**；手也盡量不入鏡，只有構圖必要時（例如伸手去拿東西、接過魔杖）才露出手，而且只露手。
  - 畫面裡的其他角色直接看向鏡頭（＝看著哈利）。
- 畫風是「事件 CG」：景深、強逆光、泛光、光粒，比立繪更有電影感。
- CG 是 1408×1408 方圖，和背景一樣會裁成橫向、直向，主要人物放中央。
- **CG 盡量顯示到畫面描寫的場面結束**，不要只出現一兩句就收起。
- 結局 CG 與結局同名。

## 八、文件標註寫法
括號裡的代號一律用引擎代號（背景代號、服裝代號、表情、旗標、結局 id）。

| 寫法 | 意思 |
|---|---|
| `場景 N　標題（背景：bg代號 中文名）` | 場景開頭（分頁裡用標題格式） |
| `［背景切換：bg代號］` | 同一場景中途換背景（換地點、換時間），寫在換背景後的第一句前一行 |
| `旁白：……` | 旁白（沒有名牌）。一行只能是說話或描寫，最多 80 字 |
| `角色名：「……」` | 對話。角色名用 `characters.md` 的名牌 |
| `［角色 登場，表情 normal］`、`［角色 表情 sad］`、`［角色 退場］`、`［全員退場］` | 立繪演出。表情只能用第五節列出的 |
| `［馬份 登場，左，表情 smug］` | 指定站位：寫「左」就排到最左；不寫就依登場順序由左到右排 |
| `［停頓］`、`［停頓 1 秒］` | 對話之間的停頓。不寫秒數＝短停頓 |
| `［角色 服裝 slytherin］`，或 `［馬份 登場，服裝 casual，表情 normal］` | 換裝，之後一直沿用 |
| `【選擇 N（一般／關鍵／分支）】題目` | 選項題目：哈利心聲的完整問句，20 字以內，不劇透 |
| `　A．「選項文字」　bond +1　f.y2c3_xxx=1` | 選項：文字＋羈絆增減＋旗標。只記旗標時寫「只記旗標」 |
| `（A）……（B）……（合流）` | 各選項後續劇情，到（合流）為止。每個選擇都要有合流，或明寫在哪裡結束 |
| `［若 f.cN_xxx=1］……［合流］` | 條件分支。可寫 `［若 f.c11_path=2 或 3］`，多個條件用 and、or、not |
| `【CG】#編號 名稱（id）：畫面說明……【CG 收起】` | CG 期間畫面一直顯示 CG |
| `［效果音 名稱］`、`［音樂 名稱］`、`［音樂 停］` | 效果音、背景音樂，放在要出聲的那一句前一行。名稱照《音樂與效果音清單》 |
| `［提示：文字］` | 隱藏數值的小提示（特殊時刻才用） |
| `［角標：幕間］`、`［角標 收起］` | 畫面左上角的小角標 |
| `［結局：y2_A 二年級結局：名稱］` | 年級結局。每個年級最後一章一定要有 |
| `［終結結局：end_ward 終結：缺席的一年］（不解鎖下一章）` | 終結結局。之後不能再有選擇 |

- **結局**一律稱「X 年級結局：名稱」，不分好壞；結局 CG 與結局同名。
- **終結結局只有三種，沿用同一個 id**：end_ward 終結：缺席的一年（重傷）、end_death 終結：沒有活下來的男孩（死亡）、end_mirror 終結：沉淪鏡中。觸發的選項要像有點騙人的合理選擇，不要明顯是送死；終結之後不能再有選擇。要新增一類終結結局，先跟 Lawch 商量。
- 章末附註：選擇數、羈絆變化範圍、路線判定、本章旗標、承接前章的旗標、CG（名稱與 id）、新背景、建議新增的表情或服裝、章名、結局（id、名稱、結局語句、結局 CG）。年級結局、終結結局、章名同時整理在總覽分頁。

## 九、交付流程
1. 劇本聊天室依本規則寫「大綱 → 劇本」，直接寫在 Claude Doc《X 年級劇本》，每次修改在該章分頁的版本紀錄加一行（改了什麼要寫具體）。
2. Lawch 審稿修改。
3. 定稿後 Lawch 交給 Claude Code，說明是第幾章第幾版。
4. Claude Code 讀文件轉成 `story/*.txt`（已轉檔的章節以 repo 的 txt 為底，只改有改動的地方）、補角色與佔位圖、同步 `story/story.js`、檢查與測試，回報結構問題；經 Lawch 確認後推送。
