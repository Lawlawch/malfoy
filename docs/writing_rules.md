# 《鉑金色的馬份｜蛇與獅之歌》劇本寫作規則

用途：劇本聊天室寫草稿時照這份規則寫。草稿交給 Lawch 審稿，定稿後由引擎聊天室轉成 `story/<章節id>.txt`。
- 引擎指令的寫法以 `story/README.md` 為準，這份不重複。
- 角色外觀、性格、口吻與已確定的設定，見 `docs/characters.md`。

---

## 一、作品設定
- 視角：哈利第一人稱，全篇繁體中文。
- 女主角：德拉科妮亞．馬份。日常稱「馬份」，家人叫她「妮亞」。傲嬌系動漫風，口是心非。
- 四個學年，每年約 10 章。一年級對應《神秘的魔法石》，有五個結局分支。
- 克拉、高爾在本作是**女生**（沿用姓氏，不寫壯碩）。
- **文風**：生動有趣，適時加入搞笑段落（例如角色的小糗事、反差的吐槽、旁白的自嘲）。搞笑點到為止，不要打斷關鍵選擇前後的氣氛。

## 二、羈絆與旗標
- 隱藏數值只有一個：**羈絆 bond**（與馬份），起始 50，範圍 0～100（引擎自動夾住），**永遠不顯示給玩家**。
  - 愈高，愈把她拉向光明；愈低，愈孤立，或被她拉向黑暗。
- 建議每章 4～8 個影響羈絆的選項（建議，不是硬性規定；劇情需要時可以更少或更多）。
  - 一般選項 ±2～5，關鍵選擇 ±8～15。
  - 純粹決定劇情走向的分支選擇，可以只記旗標、不動羈絆，避免懲罰玩家選路線。
- 旗標記錄選擇結果，讓後面的劇情對得上。命名用 `c章節_事件=數字`，例如 `c1_hagrid=2`（跨章有效）。
- 選擇之後**不在畫面提示對哪個角色有影響**。隱藏數值的暗示只在特殊時刻用，草稿標 `［提示：文字］`。

## 四、硬規則
1. **一行只能是說話，或只能是動作／心理／環境描寫，不可混在一起。** 動作寫成獨立的旁白行。
2. **一行＝一個對話框，最多 80 字。** 超過就拆成兩行。
3. **角色一出場就以名字當說話者**（大家都知道哈利波特的人物）。`？？？` 只用於**刻意隱藏身份**的角色。旁白依哈利的視角：哈利還不知道對方名字時，旁白可以稱「那女孩」「那個男人」。
4. **旁白＝說話者寫「旁白」**，遊戲裡跟對話用同一個墨綠對話框，只是沒有名牌、字色稍淡。哈利說話，說話者寫「哈利」。
5. 不要在同一行寫兩個人說話。
6. 用全形標點與「」對白；不用引號當強調（確有需要才用，一章最多三處）。
7. **選項出現前的最後一句，會在選擇時留在畫面上**，要寫成能引出選擇的一句（提問、僵局、危機）。
8. 選項文字是說話就加「」；是動作可以直接寫，也可以用（ ）（例：握住她的手、（握緊拳頭））。
9. **表情只能用第五節表格列出的表情。** 要新增表情，先跟 Lawch 確認。
10. **選擇題目**會直接顯示在遊戲的選項上方：寫成一句完整的問句，用哈利的心聲（例：「她向我伸出了手，我該怎麼做？」），**20 字以內**，不要劇透選項的後果。「一般／關鍵／分支」等分類寫在題目前的括號裡，只供參考，不會顯示。

## 五、立繪表情
分級原則：重要角色表情較多；少數重要女性角色有 shy；非重要角色表情較少；**路人角色預設只有 normal**。

| 角色 | 立繪表情 |
|---|---|
| 馬份 | normal、happy、sad、angry、shy、surprised、smug、panic、pout、cry（貴族服、校服兩套都有） |
| 榮恩 | normal、happy、sad、angry、surprised |
| 妙麗 | normal、happy、sad、angry、shy、surprised |
| 海格 | normal、happy、sad |
| 衛斯理太太、奧利凡德、摩金夫人、克拉、高爾 | normal |
| 哈利 | 無立繪（第一人稱） |

- smug（高傲、挑釁的笑）、panic（驚慌、慌了手腳）、pout（撒嬌、嘟嘴）、cry（哭）目前是馬份限定。
  - panic 和 surprised 的分別：surprised 是愣住，panic 是手足無措。
  - pout 一年級少用（她還是口是心非的對手），羈絆高時再多用；cry 留給真正的重頭戲。
- 馬份的髮色一律寫「淺金色」。
- **服裝**：馬份有兩套服裝，貴族服（入學前的便服）和校服。換裝時在草稿標 `［馬份 服裝 校服］`，或在登場時寫 `［馬份 登場，服裝 貴族服，表情 normal］`；之後一直沿用，直到下一次換裝。入學前一律貴族服，搭上霍格華茲特快車起穿校服。
- 新角色直接寫名字即可，引擎聊天室會補登記與佔位圖，圖由 Lawch 另外生成。
- 同一個畫面最多三個立繪（左、中、右）。

## 六、背景
已有：diagon_alley 斜角巷、malkin_shop 摩金夫人長袍店、kings_cross 國王十字車站、train_compartment 列車車廂、hogsmeade_station 活米村車站。
第一章新增（待生圖）：ollivanders 奧利凡德魔杖店、eeylops 咿啦貓頭鷹商店、leaky_cauldron 破釜酒吧。

- 新背景在草稿中寫「背景（新增）：代號 名稱——一句話描述」。代號用英文小寫加底線。
- 背景圖是 1920×1920 方圖，遊戲等比例裁切填滿，重要內容放**中央正方形安全區**（橫向會裁掉上下，直向會裁掉左右，各約 280px）。

## 七、草稿格式
- **交付格式：txt 檔，每行之間空一行（隔行），方便審閱。**
- 草稿開頭寫「學年、章節編號、標題」，結尾寫附註，列出選擇數、各路線羈絆範圍、旗標、CG、新背景、新角色。

```
### 場景 N　場景名（背景：代號 名稱）
旁白：……
哈利：「……」
馬份：「……」

【選擇 N（一般／關鍵／分支，只記旗標）】題目
　　A．「選項台詞」　　bond +3　　f.cN_xxx=1
　　B．選項動作　　　　bond ±0　　f.cN_xxx=2
（A）……該選項之後的台詞
（B）……
（合流）……所有選項共用的後續台詞

【CG】#編號 圖名：一句話描述畫面
```

演出標註（寫在［　］裡，引擎聊天室會轉成指令）：

| 草稿標註 | 意思 |
|---|---|
| `［馬份 登場，表情 angry］` | 角色上場（不寫表情＝normal） |
| `［馬份 表情 shy］` | 換表情 |
| `［馬份 退場］` | 角色退場 |
| `［馬份 服裝 校服］` | 換服裝（之後一直沿用） |
| `［背景切換：ollivanders］` | 同一場景中換背景 |
| `［若 f.c1_hand=1］`……`［以下共用］` | 依旗標分支的段落 |
| `［BGM：氣氛描述］`、`［音效：描述］` | 音樂、音效（目前還沒有素材，先標註） |
| `［提示：文字］` | 隱藏數值的小提示（特殊時刻才用） |
| `［結局：名稱］` | 解鎖結局圖鑑。**每個年級最後一章一定要有**：年級結算頁會顯示這一輪的結局 CG 與標題 |

## 八、交付流程
1. 劇本聊天室依本規則寫「大綱 → 草稿」。
2. Lawch 審稿修改。
3. 定稿交給引擎聊天室，說明對應哪一章。
4. 引擎聊天室轉成 `story/*.txt`、補角色與佔位圖、更新 `story/story.js`、跑 `node tools/check_story.mjs`，經 Lawch 確認後推送。
