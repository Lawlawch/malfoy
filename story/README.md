# 劇本寫法

每一章一個檔案：`story/<章節id>.txt`（例如 `story/ch1_01.txt`），章節清單、角色、圖鑑在 `story/story.js`。
寫完執行 `node tools/check_story.mjs` 檢查。網址加 `?debug=1` 時，劇本有錯會在畫面上提示。

## 基本

```
; 分號開頭是註解

@scene a_alley              ← 場景開頭（同時是存檔錨點）
@bg diagon_alley            ← 背景（assets/bg/diagon_alley.jpg）

#                           ← 旁白（跟對話同一個框，沒有名牌）
對角巷的石板路上擠滿了人。    ← 一行 = 一個對話框
昨天之前，我還是個……         ← 說話者沿用到下一個 #

@show hagrid normal
#海格
「哈利，你得去摩金夫人那裡訂做長袍。」
@face hagrid happy
「你弄完就在外頭等我。」
@hide hagrid
```

- 每個對話框最多 **80 字**，超過檢查工具會報錯。
- 說話與動作描寫分開寫成兩行。
- `#名字` 的名字對應 `story.js` 的角色名稱（自動找到立繪與頭像）。刻意隱藏身分時寫 `#？？？|draconia`（名牌顯示 ？？？，但說話時她的立繪會亮起）。
- **場景、標籤、`@if`／`@elif`／`@else`／`@endif` 之後要重寫 `#`**，避免沿用到別條分支的說話者。

## 指令

| 指令 | 說明 |
|---|---|
| `@scene id` | 場景開頭。清空立繪；後面要接 `@bg`。id 用過就不要改名、不要重複 |
| `@bg 名稱 [fade=800]` | 換背景（淡入毫秒） |
| `@show 角色 [表情] [left] [fade=300]` | 角色登場（1 人置中、2 人左右、3 人左中右；`left` 排到最左） |
| `@face 角色 表情` | 換表情 |
| `@outfit 角色 服裝` | 換裝（例：`@outfit draconia school`）。之後的 `@show`／`@face` 都用這套，跨場景、跨章節沿用到下一次 `@outfit`。角色在台上時立刻換圖，保留表情與位置。只有 `story.js` 有 `outfits` 的角色能用 |
| `@hide 角色 [fade=300]`、`@hideall` | 退場 |
| `@wait 毫秒` | 停頓 |
| `@bgm 名稱 [fade=1000]`、`@bgm stop` | 背景音樂（assets/bgm/名稱.mp3） |
| `@se 名稱`、`@voice 名稱` | 效果音（assets/sound/）、語音（assets/voice/） |
| `@bond +3`、`@set c1_open=1` | 改數值（羈絆自動夾在 0～100） |
| `@jump *標籤` | 跳到標籤 |
| `*標籤` | 標籤（英數與底線） |
| `@if 條件` / `@elif 條件` / `@else` / `@endif` | 分支。條件：`c1_hagrid == 1`、`bond >= 60 and c2_hand == 1`、`not c1_open` |
| `@showcg cg_wandshop [fade=600]` | 劇情中顯示 CG（蓋住背景與立繪，對話框在上面），同時解鎖圖鑑。圖檔 `assets/cg/<id>.jpg`，沒有圖時顯示佔位畫面 |
| `@hidecg [fade=600]` | 收起 CG（進入新場景時也會自動收起） |
| `@cg cg_wandshop`、`@ending y1_A` | 只解鎖圖鑑，不顯示 |
| `@hint 文字` | 小提示（隱藏數值的暗示，特殊時刻才用） |
| `@end` | 提早結束這一章（檔案結尾也會自動結束） |

## 選項

```
#
她斜眼打量著我那件還別著大頭針的袍子。     ← 選項前最後一句：打完字直接出選項
@choice 她問我是誰，我該怎麼回答？          ← 題目（可省略）：顯示在選項上方
- 「對，今年入學。妳也是嗎？」 -> *c1_a | bond+3 c1_open=1
- 「……妳是誰？」 -> *c1_b | c1_open=2
```

格式：`- 選項文字 -> *目標標籤 | 效果`（效果可省略，多個用空格分開）。
題目寫在 `@choice` 後面，就是草稿的「【選擇 N】題目」：一句哈利心聲的完整問句，20 字以內，不劇透後果（見 `docs/writing_rules.md` 第四節第 10 條）。草稿題目前括號裡的「一般／關鍵／分支」分類不要寫進來。超過 20 字檢查工具會提醒。

## 存檔與劇本更新

- 改錯字、改台詞內容：舊存檔照常讀取。
- 增刪句子、選項、標籤：舊存檔會用存檔那一句的內容找回原位置；那一句被改寫，就回到它前面最近一句沒改過的句子。
- 刪除場景或改了 `@scene` 的 id：舊存檔才會退回章節開頭，數值還原成當時的值。所以 **`@scene` 的 id 用過就不要改**。
- 都不需要手動改版本號。
