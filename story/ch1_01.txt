; 一年級　第一章　長袍店的金髮少女
; 視角：哈利（第一人稱）
; 隱藏數值：f.bond 羈絆（0～100，起始 50，選項寫 bond+3 增減）
; 選擇旗標：f.c1_open（初次回應）/ f.c1_hagrid（對海格的態度）
;==============================================================

;==============================================================
; 場景一　對角巷
;==============================================================
@scene a_alley
@bg diagon_alley
@wait 400

#
對角巷的石板路上擠滿了人。斗篷、尖帽、關在籠子裡的貓頭鷹，每一樣東西都像是從故事書裡跑出來的。
昨天之前，我還是個睡在樓梯底下櫥櫃裡的男孩。
今天，我卻站在魔法世界的街道上，連呼吸都覺得不太真實。

@show hagrid normal

#海格
「哈利，你得去摩金夫人那裡訂做長袍。就是前面那家店。」
「我先去酒吧喝杯東西定定神。那些妖精的小推車，坐得我胃都翻過來了。」
@face hagrid happy
「你弄完就在外頭等我，很快就回來。」

#
我點點頭，看著他寬闊的背影擠過人群，像一座會走路的小山。
@hide hagrid

;==============================================================
; 場景二　摩金夫人的長袍店
;==============================================================
@scene a_shop
@bg malkin_shop
@wait 300

@show malkin normal
#摩金夫人
「霍格華茲的新生嗎，親愛的？」
「來得正好，這邊還有一個位子。上來站到凳子上吧。」
@hide malkin

#
我踩上凳子，一件別滿大頭針的黑袍被披到我肩上。
這時我才發現，旁邊的凳子上早就站著另一個人。

@show draconia normal
是個和我差不多年紀的女孩。淺金色的頭髮梳得一絲不苟，下巴微微抬著，站在凳子上的樣子，簡直像站在王座前。
#馬份
「……你也是要去霍格華茲的？」
#
她斜眼打量著我那件還別著大頭針的袍子。

;--- 選擇一：怎麼回應她 ----------------------------------------
@choice
- 「對，今年入學。妳也是嗎？」 -> *c1_a | bond+3 c1_open=1
- 「……妳是誰？」 -> *c1_b | c1_open=2
- 「對。妳看起來很習慣被人伺候。」 -> *c1_c | c1_open=3

*c1_a
#哈利
「對，今年入學。妳也是嗎？」
#馬份
「那還用說。馬份家的人不去霍格華茲，還能去哪裡？」
@face draconia happy
「……哼。你比我想的要有禮貌一點。」
@jump *c1_end

*c1_b
#哈利
「……妳是誰？」
@face draconia angry
#馬份

「哼，聽好了。你最好把這件事記清楚。」
@jump *c1_end

*c1_c
#哈利
「對。妳看起來很習慣被人伺候。」
@face draconia shy
#馬份
「什、什麼？！我只是站得端正一點而已！」
「這叫教養！你懂不懂什麼是教養？」
#
旁邊的摩金夫人忍著笑，繼續替她量袖長。
@jump *c1_end

*c1_end
@face draconia normal
#馬份
「我叫德拉科妮亞．馬份。純血的馬份家，你總該聽過吧？」
#
我只好含糊地「嗯」了一聲。
#馬份
「我已經決定要進史萊哲林了。我們家每一代都是。」
「你呢？魁地奇總該有支喜歡的球隊吧？」
#哈利
「魁地奇……是什麼？」

@face draconia angry
#馬份
「你、你連魁地奇都不知道？！」
「你該不會是在麻瓜家裡長大的吧？」
#哈利
「……可以這麼說。」
#
她深深吸了一口氣，像是在說服自己不要昏倒。
@face draconia shy
#馬份
「真是的……我只說一次，你給我聽好。」
「四顆球，七名球員。找球手抓到金探子，比賽就結束。」
@face draconia happy
「我以後要當史萊哲林的找球手。一年級不能帶自己的掃帚，這規定根本是愚蠢！」
#
說到飛行，她的眼睛亮了起來，剛才那種高高在上的語氣，一下子淡了許多。
@face draconia normal

;--- 窗外的海格 ------------------------------------------------
就在這時，她的視線越過我，落在窗外。
海格站在街對面，一手一支冰淇淋，正笨拙地朝我揮手。
#馬份
「那個高得離譜的人……是跟你一起的？」
「我聽說，他住在校園邊的小屋裡，粗魯得像野人，酒喝得比誰都多。」

;--- 選擇二：怎麼面對這句話 --------------------------------------
@choice
- 「他是我的朋友。把那句話收回去。」 -> *h_a | c1_hagrid=1
- 「妳又沒見過他，怎麼知道他是什麼樣的人？」 -> *h_b | bond+3 c1_hagrid=2
- （握緊手心，什麼也沒說） -> *h_c | c1_hagrid=3

@face draconia angry

#馬份
「……你不反駁嗎？」

#馬份
「……真無趣。」
#
她把頭轉開了。但抓著袍角的手指，好像僵了一下。
@jump *h_end

*h_end
@face draconia normal

「……他們已經不在了。」
@face draconia sad
#馬份
「……」
「……抱歉。我不該問的。」
@face draconia shy
「我只是隨口問問！才、才不是故意要提起你的傷心事！」

她的耳朵尖紅了一小塊，目光卻怎麼也不肯看向我。

;--- 道別 ------------------------------------------------------
#摩金夫人

@face draconia normal

#馬份
「對了，還沒問你的名字。」

@face draconia shy
#馬份

「那個——」

「我、我才不是對你有興趣！只是覺得，你這個名字，我會記住的。」

@hide draconia fade=400
#
她踩著小碎步走出店門，銀金色的髮尾在陽光裡晃了一下，就不見了。
